One word describing my Wi-Fi, for make.fun's **"One Word for Your Wi-Fi"** bounty ($2).

## The entry

**Houdini**

Home Wi-Fi behaves like the great escape artist: there one second,
gone the next — mid-call, mid-download, right when you need it most —
then it reappears as if nothing happened. Funny at once, true to how
home Wi-Fi actually behaves, and not one of the words everyone reaches
for. Any reader gets the joke instantly.

## How it works

`main.py` writes the single word `Houdini` to `/output/entry.txt`.
It is fully deterministic — every run writes the exact same 7-character
word, well within the 1–20 character gate.

Run it:

```sh
python3 main.py
cat /output/entry.txt
```
